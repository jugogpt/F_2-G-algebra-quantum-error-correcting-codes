# Module Theory for Quantum Codes over Group Algebras

Python code and data for the paper "Module Theory for Quantum Codes over Group Algebras" by AJ Davenport, Hugo Sanchez, and Isaac Chuang.

The repository implements the Part II toolchain for t-variate bicycle codes over R = F2[Z_l1 x ... x Z_lt]. This includes CRT decomposition of R into local rings, detection of semilinear symmetries from the generators, inverse design of codes with prescribed symmetries, logical operators, exact distance, and the logical group generated by a code's symmetries. `data/` holds the tables behind the computational claims, and `scripts/` regenerates them. `tests/` reproduces the paper's worked examples.

## Requirements

- Python 3.10+ (tested on 3.13)
- `numpy`, `scipy` (HiGHS ILP for distance), `sympy` (Schreier-Sims for group orders), `galois` (GF(2^m) arithmetic), `pandas` (search scripts only)
- `pytest` for the tests

No other dependencies. `pip install -r requirements.txt`.

## Modules (`src/`)

**Ring and codes** (Sec. V)

| Module | Description |
|---|---|
| `bb_core.py` | Ring setup, CRT components, residue degrees D_c |
| `bb_ring_elt.py` | Elements of R, automorphism action, Hasse-Taylor jets at a component |
| `bb_local_ring.py` | Arithmetic in a local component, scalar matching solver |
| `bb_crt.py` | CRT reconstruction of global elements from local data |
| `bb_logical.py` | Dimension count and logical operator basis (Algorithm 1) |
| `bb_distance.py` | Exact minimum distance by per-logical ILP, with an early-exit threshold |

**Detection and design** (Sec. VI)

| Module | Description |
|---|---|
| `bb_automorphisms.py` | Aut(G) as integer matrices, named catalog, local-ideal filter |
| `bb_theta.py` | Depth-one unitary layers over Sp(4,F2) |
| `bb_script_a.py` | Script A: find all semilinear symmetries psi, Theta of a code |
| `bb_symcheck.py` | Uncapped symmetry test on bit vectors (same output as Script A, faster) |
| `bb_script_b.py`, `bb_theta_inverse.py` | Script B: inverse construction from a prescribed symmetry |
| `bb_gamma.py` | Inverse design for a set of automorphism, fold and automorphism+fold gates |
| `bb_orbits.py` | Orbit decomposition of the joint solution space |
| `bb_kdist.py` | Exact distribution of k over all codes of a solution space |
| `bb_lowweight.py` | Sparsest generator pair of a module |
| `bb_equiv.py` | Equivalence of pairs (f1, f2) under Aut(G), translations, f1 <-> f2 |

**Logical action and group**

| Module | Description |
|---|---|
| `bb_logical_action.py` | Matrix of a symmetry on the logical space |
| `bb_fold_s.py` | Fold gates (x\|z) -> (x\|z + Px) from involutive pairings of qubits |
| `bb_wide.py` | Wider class: independent psi_L, psi_R, block exchange |
| `bb_fullgroup.py` | Logical group from all certified symmetries (`narrow_group_mats`, `full_group_mats`) |
| `bb_logical_group.py` | Order, clusters and fullness of a subgroup of Sp(2k,2) |
| `bb_prove_full.py` | Proof that a subgroup is all of Sp(2k,2): transvection and transitivity |
| `bb_clifford_order.py`, `gate_naming.py` | Group order and gate names for k <= 2 |
| `bb_sweep.py` | Sweep driver: enumerate, screen by distance, classify group, write CSV |

## Quick start

```python
import sys; sys.path.insert(0, "src")
from bb_core import ring_setup
from bb_ring_elt import RingElement as RE
from bb_logical import code_dimension
from bb_distance import code_distance
from bb_fullgroup import narrow_group_mats
from bb_prove_full import prove_full

L = (3, 3)
rd = ring_setup(L)                                   # CRT components of F2[x,y]/(x^3+1, y^3+1)
f1, f2 = RE.from_string(L, "1 + x + y"), RE.from_string(L, "1 + y + x^2*y")
code_dimension(f1, f2, rd)                           # 4
code_distance(f1, f2, rd)["d"]                       # 4 (exact)
mats, k, info = narrow_group_mats(f1, f2, rd)        # logical action of every certified symmetry
prove_full(mats, k)["verdict"]                       # 'full': the group is all of Sp(8,2)
```

## API reference

```python
ring_setup(L) -> RingData
```
`L` is the tuple (l_1, ..., l_t). `.components` has `Dc` (residue degree), `dim` (local dimension), `index`, `rep` (root representative).

```python
code_dimension(f1, f2, rd) -> int
logical_basis(f1, f2, rd) -> (LX, LZ)
code_distance(f1, f2, rd, reject_below=None, time_limit=None) -> dict
```
Keys: `d`, `dX`, `dZ`, `exact`, and `below_target`. With `reject_below=d0`, the search stops at the first logical word of weight below `d0`; then `d` is an upper bound and `below_target` is `True`.

```python
find_symmetries(f1, f2, rd, include_depth1=True) -> list[dict]
```
All semilinear symmetries (psi, Theta) of the code. Exact for the class sigma = Phi_psi o Theta. Fold gates and the wide class are separate (`bb_fold_s`, `bb_wide`).

```python
narrow_group_mats(f1, f2, rd, use_fold=True) -> (mats, k, info)
full_group_mats(f1, f2, rd, use_wide=True, use_fold=True) -> (mats, k, info)
classify_logical_group(mats, k, max_points=3000) -> dict
prove_full(mats, k) -> {"verdict": ...}
```
`mats` are the 2k x 2k matrices over F2 of the symmetries and translations acting on the logical space. `classify_logical_group` gives the exact order and clusters when k <= 6. `prove_full` is the only fullness test for larger k. `'full'` is a proof. Any other verdict means only that no proof was found.

`full_group_mats` with the wide class is slow for large rings. Use `narrow_group_mats` there.

```python
sample_gamma(rd, rng, n_auto=2, n_fold=2, n_autofold=2)
gamma_basis(L, gens) -> solution basis for (f1, f2)
```
Inverse design: the gate constraints are linear in (f1, f2) for fixed twists.

## Reproducing the results

```bash
pytest tests -q                    # fast checks, seconds
pytest tests -q -m slow            # Example 5 group is full Sp(8,2), minutes
python scripts/verify_examples.py  # asserts every number in the worked examples
python scripts/build_data.py       # rebuilds data/csv/ from data/raw/
```

Search drivers. They read and write in the working directory, so run them from `scripts/`. Scripts that read earlier outputs (`k6_group.py`, `k6_narrow.py`, `commutant.py`) expect the file from `data/raw/` to be copied there. Arguments are in each script's header.

| Script | Purpose |
|---|---|
| `enum_k.py` | Enumerate inequivalent pairs of bounded weight with a given k |
| `find_full.py` | Distance, logical group and fullness for each enumerated code |
| `sample_k8.py`, `find_full2.py` | Z5xZ5, k=8: sample codes vanishing on one component (`sample_k8.py seed max_weight n_samples out.pkl`), then test them |
| `commutant.py` | Commutant of the generated group (dimension > 1 proves the group is not full) |
| `k6_group.py`, `k6_narrow.py` | Logical groups for the k=6 codes (wide / narrow class) |

## Limits

- Symmetries found are those in the classes above; other automorphisms or Clifford circuits that preserve a code are not detected.
- Hamming weight is not a module invariant, so distance is computed separately and is exact only when `exact` is `True`.
- A `not_full` verdict in `data/csv/logical_groups_k_gt2.csv` refers to the symmetry class listed in `symmetry_class`. Wide gates were not tested on every code.
- `undecided` means no transvection was found. It is not a proof that the group is smaller than Sp(2k,2).
