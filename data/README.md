# Data

`csv/` holds the tables. `raw/` holds the run outputs they are built from (`python scripts/build_data.py`). All polynomials are written in x, y with exponents mod l_i. A ring `Z12xZ6` is F2[x,y]/(x^12+1, y^6+1).

## Conventions

- `d_status`: `exact` (distance proven), `upper_bound` (a logical word of weight `d` was found while screening for a target; true distance is at most `d`), or `unresolved`.
- `outcome` (screens):

| value | meaning |
|---|---|
| `below_target_d` | A logical word lighter than the target was found; the code is dropped. The rejection is rigorous, `d` is only an upper bound. Target: the gross code's k d^2/n unless stated. |
| `over_weight_budget` | `check_weight` exceeded the allowed maximum; not evaluated. |
| `screen_timeout` | Screening hit its time limit before settling the target. |
| `evaluated` | Exact distance computed. |

- `kd2_over_n` is k d^2 / n. Gross code: 12. Two-gross code [[288,12,18]]: 13.5.
- One row per equivalence class of (f1, f2) under Aut(G), translations of each polynomial, and f1 <-> f2. `class_id` identifies the class.

## `crt_components.csv`

CRT components of R for the rings used in the paper and the searches.

| column | meaning |
|---|---|
| `ring`, `L` | Group G and its tuple of orders |
| `n_qubits` | 2\|G\| |
| `component` | Component index; 0 is the trivial component (1,...,1) |
| `D_c` | Degree of the residue field F_{2^{D_c}} |
| `local_dim` | F2-dimension of the local ring J_c |
| `conjugate_component` | Index of c* under the bar involution |
| `self_conjugate` | `True` if c* = c |

Gross code ring `Z12xZ6`: components of D_c = 1, 2, 2, 2, 2 and local dimensions 8, 16, 16, 16, 16 (sum 72). Two-gross `Z12xZ12`: D_c = 1, 2, 2, 2, 2 and local dimensions 16, 32, 32, 32, 32 (sum 144). `Z5xZ5` has six components with D_c = 4, all self-conjugate.

## `code_screen.csv`

One row per class from the sweeps (Z9 with k=2; gross-scale Z9xZ9, Z10xZ6, Z12xZ6, Z14xZ6, Z15xZ6; k=6 rings Z3xZ3, Z4xZ4, Z3xZ6, Z6xZ6).

| column | meaning |
|---|---|
| `ring`, `n`, `k`, `f1`, `f2` | Code |
| `check_weight` | wt(f1) + wt(f2) |
| `outcome`, `d`, `d_status` | See conventions |
| `kd2_over_n`, `beats_gross`, `beats_two_gross` | Figure of merit versus the two baselines (blank unless `evaluated`) |
| `n_symmetry_gens` | Symmetry generators used for the logical group |
| `logical_group_order`, `group_status` | Order of the logical group and whether it is exact |
| `acts_as_full_Sp` | Group is all of Sp(2k,2) (decided for k <= 3 here) |
| `class_id`, `source` | Class key and the raw file it came from |

Summary: on `Z12xZ6` the screen leaves only the gross code, `[[144,12,12]]`, exact d = 12 (`source = exact_survivors.csv`). The two `screen_timeout` rows in `gross_family_12x6.csv` are the gross code and a relabeled copy.

## `logical_groups_k_gt2.csv`

Logical group generated by a code's certified symmetries, for codes with k > 2.

| column | meaning |
|---|---|
| `symmetry_class` | `narrow`: semilinear maps, translations and fold gates. `wide`: also independent psi_L, psi_R and block exchange |
| `n_generators` | Matrices used |
| `logical_group_order` | Exact order (k <= 6); blank when infeasible |
| `verdict` | `full`: proven equal to Sp(2k,2). `not_full:exact_order`: order below \|Sp(2k,2)\|. `not_full:nilradical_certificate`: a proper invariant subspace exists. `not_full:commutant_certificate`: the generated group has commutant of dimension `commutant_dim` > 1. `undecided`: no transvection found; no claim |
| `same_as_example5` | Equivalent to the paper's Example 5 code (Z3xZ3 only) |

| ring | k | classes | full | not full | undecided |
|---|---|---|---|---|---|
| Z3xZ3 | 4 | 7 | 1 (Example 5) | 6 | 0 |
| Z3xZ6 | 6 | 2 | 0 | 2 | 0 |
| Z4xZ4 | 6 | 16 | 0 | 16 | 0 |
| Z6xZ6 | 6 | 16 | 0 | 16 | 0 |
| Z5xZ5 | 8 | 10 (sampled) | 0 | 3 | 7 |

The Z5xZ5 rows are a random sample of codes whose f1, f2 vanish on one degree-4 component, not an enumeration. Of the first three, the commutant has dimension 16, 16 and 4. A full group has commutant dimension 1.

## `r9_wide_class.csv`

The 60 Z9 (k=2, d=4) codes whose semilinear group is not Sp(4,2), re-analysed with the wide class. `order_wide` is the order with the wide class; `order_wide_plus_foldS` adds fold gates. All 60 reach 720 = \|Sp(4,2)\|.

## `mcr_validation.csv`

Reproduction of Table 4 of the earlier cyclic-submodule paper (MCR codes, k = 2): l = 9, 11, 15, 25, 27.

| column | meaning |
|---|---|
| `d_paper`, `d_computed`, `d_exact` | Distance from the paper, ours, and whether ours is proven |
| `gates_paper` | Generators reported in the paper |
| `n_semilinear_syms`, `order_semilinear` | Semilinear symmetries found and the order of their logical group |
| `n_foldS`, `order_with_foldS`, `full_with_foldS` | Same with fold gates; `full` means order 720 |

All five distances match. With fold gates l = 9, 11, 27 reach the full Sp(4,2); l = 15, 25 do not (order 36). l = 29, 33 were not run.
